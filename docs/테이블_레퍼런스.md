## 분석 전에 알아 둘 것

1. 고객 단위 분석은 `customers` (50,000) 를 분모로 둔다. support_tickets 를 그대로 LEFT JOIN 하면 59,391행으로 불어나니 고객별로 먼저 묶는다.
2. `is_recontact` 는 정의가 확인되지 않았다 (true 의 71.9% 는 이전 문의 없음). 재문의 숫자는 «표시 기준» 이라고 밝힌다.
3. 해결 시간은 `status = '완료'` 로 거르고, 상담 시간 (`duration_min`) 은 채널 비교에 쓰지 않는다.
4. 해지는 2025년에만 기록되어 있다. 가입 연도별 해지율 · 2025년 이전 이탈은 이 데이터로 말하지 않는다.
5. `campaign_id` 는 customers · sessions 모두 캠페인 기간과 맞지 않는다 (가입 895 / 6,485 · 세션 25,753 / 182,116 만 기간 안). 캠페인 단위로는 ad_spend (기간 · 예산과 맞음) 만 쓰고, 획득은 `acquisition_channel` 로 본다. `customer_name` 은 쓰지 않는다.
